## 五种风格配方

### 1. 暗色科技风（Dark Tech · Linear / Vercel 系）

- **气质**：开发者工具的"高级黑"，冷峻专业。
- **配色**：近黑三层 `#050507` / `#0a0a0f` / `#111017` 分层；紫 `#8b5cf6` → 青 `#22d3ee` 渐变做强调与渐变文字。
- **手法**：全页噪点（feTurbulence SVG data-URI）、径向光晕、玻璃吸顶导航（半透明 + blur）、行情跑马灯、纯 CSS 手机模型。
- **慎用**：用户嫌黑——若采用必须整体提亮一档。

### 2. Bento 网格（Apple 发布会风）★ 主推

- **气质**：信息密度高但井然有序，一屏讲完所有卖点。
- **布局**：12 列网格大小格混排（占 6/4/3/2 列的格子拼贴），行尾点缀数据小格（17MB / 7 天试用 / 版本号）。
- **深色版**：底 `#0d0d0d`，六格各配一色：蓝 `#3987e5` 红 `#e66767` 紫 `#9085e9` 橙 `#d95926` 黄 `#c98500` 品红 `#d55181`。
- **浅色版（当前方向）**：暖白纸感底 `#f7f6f3`，格子白渐变 `#fbfaf7→#fff`，文字三档 `#1a1a19`/`#52514e`/`#6f6d66`，六色重校为白底可读的深色系：蓝 `#1f66b8` 红 `#d03b3b` 紫 `#6357d6` 橙 `#bc4a10` 金 `#6f4c00` 品红 `#b23a68`（全部 ≥4.5:1）；柔和双层投影；A 股红涨绿跌保留（涨 `#d03b3b` 跌 `#0a810a`）。
- **手法**：内嵌 mock（聊天、分时折线、筹码峰）、滚动触发描线动画。

### 3. 玻璃拟态 × 极光（Glassmorphism · Liquid Glass 2026）

- **气质**：梦幻流动，2026 最热方向。
- **配色（深色）**：深空底 `#06070f`，五个极光色 `#7c5cff`/`#29d3ff`/`#ff5cae`/`#3ddc97`/`#6366f1` 持续流动。
- **手法**：磨砂玻璃卡 `backdrop-filter: blur(18px) saturate(170%)` + 内高光、hover 极光彩影、推荐档 conic 旋转描边。

### 4. 极简编辑排版（Minimal Editorial · Swiss 风）

- **气质**：安静、高级、耐读，"杂志感"。
- **配色**：暖白 `#FAF9F5` 大留白，全文单一朱红强调 `#BE3B21`。
- **手法**：衬线大标题（Songti SC 栈）、hairline 细线分区替代卡片盒、01–06 编号系统贯穿全站。

### 5. 新粗野主义（Neo-Brutalism）

- **气质**：反精致，个性最强、最有记忆点。
- **配色**：奶油纸底 `#FAF3E7` + 黄 `#FFDE59` / 粉 `#FF90E8` / 柠檬绿 `#B8F135` / 亮蓝 `#7EB6FF` 撞色。
- **手法**：3px 粗黑边框、无模糊硬投影（偏移实心阴影）、900 字重大标题、贴纸式旋转元素、双条跑马灯。

## 流动极光（浅色版）参数实录

出自 `bento-light.html`（源自智谱 open.bigmodel.cn 的效果复刻，浅色适配）：

- **实现**：body 首个子节点的绝对定位层，`z-index:-1`、`height:160vh`（不 fixed，随滚动自然离开）、`overflow:hidden`、`pointer-events:none`。
- **色斑**：5 个 42–60vmax 大软边圆斑，radial-gradient 三段软边（46% 中段 / 72% 全透明，**不用 filter:blur**）：
  蓝 `rgba(42,120,214,.24)`、紫 `rgba(99,87,214,.22)` 为主角（hero 左上/右上），青 `rgba(25,158,112,.16)`、品红 `rgba(178,58,104,.15)`、深蓝 `rgba(31,102,184,.18)` 辅助。
- **动画**：`ease-in-out infinite alternate`，周期 36/30/42/26/33s，负延迟 −4/−13/−22/−9/−17s 错相；位移 6–12vmax + scale 0.92–1.15 + ±6–8° rotate，个别叠 opacity 呼吸。
- **纵向渐隐**：`mask-image` 线性渐变——0–38% 全强、66% 减半、94% 归零（hero 最明显，等级区以下回素底）。
- **可读性关键**：白卡片本身不透明（白渐变底），极光只从卡片间隙透出，卡内对比度零损失。
- **性能**：只动 transform/opacity（合成器层），不用 will-change；全局 `prefers-reduced-motion: reduce` 冻结为静态淡彩。

## 正式站落地实录（2026-08-30 迁移）

浅色 Bento + 极光已从风格稿迁入 Astro 正式站（四页：主页 / `pricing` 订阅 / `login` 登录 / `account` 用户中心），迁移时的关键决定：

- **令牌改名**：风格稿 `--ink` → 正式站 `--ink-1`；`--yellow` → `--gold`（类名 `cell--yellow` → `cell--gold`）。其余令牌名不变。
- **共享壳组件化**：`Layout.astro`（令牌 + 全局类 + SVG 雪碧图）、`Nav.astro`（`variant: home|sub` + 可选 `avatar` 登录态）、`Footer.astro`、`Aurora.astro`（`strength: full|soft`）。页面间零复制粘贴。
- **极光分级**：主页/订阅页 full，登录/用户中心 soft（整层 opacity .55 或色斑再降一档）——内容型页面背景要更安静。
- **版本常量集中**：`src/config.ts`（VERSION/VCODE/APK/GITHUB/MIRROR/SHA256），APK 路径从版本号派生；APK 文件在 `public/apk/`（gitignore，curl 获取，命令在 CLAUDE.md）。
- **下载模块定稿结构**：直链大按钮（56px 高、唯一强 CTA）+ 版本行 + SHA256 折叠 + 手绘二维码格（占位待真码）+ 安装指引 details + 「其他下载方式」折叠（GitHub 降级为无 logo 文字链 + ghfast 镜像代码块）。全站所有下载入口统一走 `APK` 直链。
- **子页规格**：订阅页 = 周期 radio（`cy-{key}`）× 价格组（`pg-{key}`）联动 + 三档卡 + 差价升级条 + 三步流程；登录页 = 模式 radio（登录/注册）驱动 tab 滑块/标题/表单/按钮文案；用户中心 = 左栏五项（账户/订阅/激活码/下载/退出）+ 订阅进度条三段刻度。全部零 JS。
- **账号体系定位**：订阅 → 发激活码 → App 内输入解锁（贴合现有激活码体系）；App 侧后端在 `lic.boboai.tech`，网站账号后续对接。网站动态数据（价格/订单/用户）目前全为带 TODO 注释的占位。



## 硬约束（任何风格稿都要守）

1. **零 JS、零外部资源、零跟踪**——自包含单文件，双击即开。
2. 全站简体中文（`lang="zh-CN"`）；文案克制、具体、不吹。
3. 正式站配色必须走设计令牌（Layout.astro `:root` 的 CSS 变量），不硬编码十六进制。
4. 文字对比度 ≥4.5:1；交互组件 hover 有反馈；移动端单列成立。
5. 用户视觉偏好：**偏亮底**。深色方案一律提亮一档，或亮暗两版并出。

## 推荐工作流

1. 按需求挑配方 → 复制对应预览文件为起点，改令牌与内容。
2. 大改派 agent 时，把本文件对应小节贴进 prompt 当规格。
3. 本地起 `server.cjs` 给用户看实际效果，别只给代码。
4. 新结论（新配色、新动效参数）及时回写本文件，保持与实稿同步。
