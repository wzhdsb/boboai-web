// FAQ · 常见问题

问之前，先看这里

需要什么配置的手机？
Android 11（API 30）及以上，无需 root。安装包约 17MB，建议 6GB 以上内存的机型以获得流畅的后台体验。
免费试用怎么算？
首次启动起 7 天全功能试用，无需注册账号。到期后输入激活码解锁，换机可自助换绑设备。
我的数据存在哪里？
聊天、自选、持仓、知识库全部本地存储，支持口令加密的一键备份导出；不经任何第三方服务器。
AI 能力需要自己提供 Key 吗？
是。对话与分析使用你自己的智谱 API Key，额度与花销自己掌控，App 内透明记账，不经过中间商。
激活后能离线用吗？
能。激活票据本地 Ed25519 验签，离线可用；联网时每 24 小时自动静默续签，无需反复输码。
