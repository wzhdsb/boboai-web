# 网页设计说明

> 本文档梳理官网的设计实现与组件清单，供协作设计时对照使用。
> 代码行号以撰写时的版本为准（commit `00f561c`），后续代码变动可能有偏移。

## 一、整体架构

- **技术路线**：Astro 静态站点，构建产物为纯 HTML/CSS，客户端**零 JavaScript**、无 UI 框架、无组件库、无跟踪脚本。
- **文件分工**（全站只有两个源文件）：

| 文件 | 职责 |
|---|---|
| `src/layouts/Layout.astro` | HTML 外壳 + 全局样式：设计令牌（CSS 变量）、基础 reset、跨板块共享的布局类 |
| `src/pages/index.astro` | 唯一页面：内容数据（frontmatter 数组）+ 标记 + 页面专属 scoped 样式 |

- **内容与样式分离**：各板块文案写成 frontmatter 里的数据数组（`features` / `tiers` / `faqs`），标记层只做 `.map()` 渲染。改文案改数组，不动标记。
- **响应式策略**：仅一条 `720px` 断点（网格塌成单列），其余靠 `clamp()` 流式字号与 `flex-wrap`。

## 二、设计系统（Design Tokens）

定义在 `src/layouts/Layout.astro` 的 `:root` 上，全站颜色、字体统一从这里取值，**不要硬编码十六进制色值**。

| 令牌 | 值 | 用途 |
|---|---|---|
| `--bg` | `#0b0e14` | 页面底色（最深层） |
| `--bg-soft` | `#10141d` | 隔段背景（次深层） |
| `--card` | `#11151f` | 卡片背景 |
| `--border` | 半透明白 | 卡片 / 分区描边 |
| `--text` / `--text-dim` / `--text-faint` | 三档灰 | 正文 / 次要 / 弱化文字，信息层级全靠这三档 |
| `--accent` | `#5b9dff` 蓝 | 主色：按钮、链接、图标 |
| `--gold` | `#e6b450` 金 | 版本标签、代码片段 |
| `--green` | `#3fb984` 绿 | 功能清单对勾 |
| `--radius` | `14px` | 统一圆角 |

字体栈：中文 HarmonyOS Sans SC → MiSans → PingFang SC → 微软雅黑；等宽 JetBrains Mono 栈。仅暗色主题。

## 三、组件清单

按页面自上而下排列，共 8 类，全部手写实现。

> 下方示意图为 ASCII 线框图，用注释标出颜色与交互（ASCII 无法呈现真实的颜色、模糊与发光效果）；查看真实效果请运行 `npm run dev`。

### 1. 顶部导航栏（Navbar）
- 位置：`src/pages/index.astro` header 部分
- 吸顶（sticky）+ 半透明毛玻璃模糊（`backdrop-filter: blur(12px)`）
- 内部两元素：
  - **品牌标识（Brand）**：手绘 SVG 图标 + "BOBO" 文字，点击回顶部
  - **导航菜单（Nav Menu）**：4 个锚点链接（功能 / 版本 / 下载 / FAQ），点击平滑滚动到对应区块；hover 文字变亮

```
┌──────────────────────────────────────────────────────┐
│ [B] BOBO                        功能   版本   下载   FAQ │
└──────────────────────────────────────────────────────┘
   ↑ 品牌 Logo                       ↑ 导航菜单（锚点跳转）

整栏吸顶 + 毛玻璃：滚动网页时始终固定在顶部，半透明地透出底下内容
```

  - **氛围光晕**：两层径向渐变伪元素铺底
  - **说明文字（meta）**：底部灰色小字

### 3. 按钮（Button）
两个变体，均带 hover 上浮 1px 反馈：

| 变体 | 类名 | 样子 | 用在哪 |
|---|---|---|---|
| 主按钮 | `.btn.primary` | 蓝色渐变实心、白字、投影 | 立即下载 / 前往下载 |
| 幽灵按钮 | `.btn.ghost` | 透明底、仅描边 | 了解功能 |

```
    主按钮 .btn.primary             幽灵按钮 .btn.ghost
   ┏━━━━━━━━━━┓                   ┌───────────┐
   ┃  立即下载 ┃                   │  了解功能  │
   ┗━━━━━━━━━━┛                   └───────────┘
   蓝色渐变实心 · 白字 · 投影       透明底 · 只有一圈描边

```

## 四、术语小词典

| 术语 | 通俗解释 |
|---|---|
| Hero | 打开页面第一眼看到的首屏大区块 |
| CTA | Call To Action，引导用户点击的按钮（如“立即下载”） |
| Kicker / 眉题 | 标题上方那行小号强调文字 |
| Sticky / 吸顶 | 滚动页面时固定在屏幕顶部不消失 |
| Hover 态 | 鼠标悬停时组件的样式变化 |
| 幽灵按钮（Ghost） | 只有描边、没有填充色的次级按钮 |
| 角标（Badge） | 悬浮在卡片角落的小胶囊（“推荐”） |
| 网格（Grid） | 把卡片排成规整行列的布局方式 |
| 手风琴（Accordion） | 点一下展开、再点收起的折叠列表 |
| 毛玻璃（Frosted glass） | 半透明 + 背景模糊的视觉效果 |
| 设计令牌（Design Token） | 把颜色/字号/圆角等提炼成 CSS 变量统一管理 |

## 五、协作设计的工作流

1. `npm run dev` 启动本地服务（http://localhost:4321），Astro 热更新，改代码保存即刷新
2. 浏览器 F12 开发者工具可现场试改 CSS，满意后落实到代码
3. 可直接把浏览器截图粘贴到 Claude Code 对话中，指哪改哪
4. `npm run preview` 预览构建产物（上线前确认用）
